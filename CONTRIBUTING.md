# Contributing

Small, focused repo — contributions are welcome, especially:

- Support for other trigger sources (n8n, Zapier, plain cron on a VPS)
- A version that also handles timezone conversion automatically
- Docs fixes / clearer setup steps

## How

1. Fork the repo
2. Create a branch (`git checkout -b feature/your-idea`)
3. Commit your changes
4. Open a PR with a short description of what/why

Bug reports and feature requests: open an issue.
